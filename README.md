# LLM Memory Persistence Example

This Python script demonstrates a simple persistent memory mechanism for an AI agent. It saves conversation history to a JSON file, allowing the agent to 'remember' past interactions across multiple turns, overcoming the stateless nature of typical LLM interactions.

## Language

`python`

## How to Run

Run the script using: python memory_demo.py
Interact with the agent by typing messages and observe how it uses its memory.
